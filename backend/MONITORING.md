# Мониторинг доступности

Публичный endpoint: `GET https://<ваш-домен>/health`.

Он возвращает `200 OK` только если FastAPI и PostgreSQL доступны:

```json
{"status":"ok","checks":{"database":"ok"}}
```

Если база недоступна, endpoint возвращает `503 Service Unavailable` без деталей подключения.

После deploy создайте HTTP(S)-монитор в UptimeRobot, Better Stack или у выбранного хостинга:

1. Укажите URL `https://<ваш-домен>/health`.
2. Установите интервал проверки 60 секунд.
3. Считайте доступным только ответ `200`.
4. Добавьте уведомления на email или Telegram.

Монитор передаёт только URL `/health`; текст пользователей, cookies, токены и данные БД в него не входят.
