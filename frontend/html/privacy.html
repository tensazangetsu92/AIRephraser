Политика конфиденциальности

Здесь описано, какие данные обрабатывает Humary, для чего это нужно и как пользователь может управлять своими данными.

Дата обновления: 3 октября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает обработку персональных данных пользователей сервиса Humary. Оператор обрабатывает данные только в объёме, необходимом для работы аккаунта, обработки текста, обеспечения безопасности и предоставления функций сервиса.

Перед открытием сайта пользователям на странице контактов будут опубликованы полные сведения об операторе персональных данных. Перед запуском реальных платежей там же будут опубликованы сведения об исполнителе платных услуг.

2. Какие данные обрабатываются

  • адрес электронной почты, дата создания аккаунта и статус аккаунта;
  • имя и ссылка на аватар, если они получены при входе через Яндекс ID или VK ID;
  • технические данные сессии, необходимые для входа, продления авторизации и защиты от перебора кодов и массовых запросов;
  • исходные тексты, результаты обработки, тип инструмента и дата запроса, сохранённые в истории аккаунта;
  • готовый Word-файл, созданный инструментом «Учебная работа», если пользователь обработал документ в этом инструменте.

3. Для чего нужны данные

  • создание и защита аккаунта, подтверждение email и поддержание авторизации;
  • передача текста в сервис обработки и показ результата пользователю;
  • ведение истории запросов, учёт лимитов слов и бесплатной пробной обработки;
  • защита сайта от злоупотреблений, техническая диагностика и устранение ошибок;
  • исполнение обязанностей, предусмотренных законодательством, если они возникнут.

4. Тексты пользователей и файлы

Текст, отправленный на обработку, передаётся в GigaChat для выполнения выбранной пользователем операции. Humary не публикует тексты пользователей и не использует их для собственных рекламных рассылок.

Исходный текст и результат сохраняются в истории, пока существует аккаунт или пока пользователь не удалит историю либо аккаунт. Для «Учебной работы» дополнительно сохраняется готовый Word-файл, чтобы пользователь мог скачать именно обработанную версию с сохранённым оформлением.

Пользователь может удалить аккаунт в профиле. При удалении из активной базы данных удаляются аккаунт, история текстов, связанные Word-файлы, сессии, баланс слов и одноразовые коды. Резервные копии могут храниться ограниченное время, необходимое для восстановления системы.

5. Cookie и localStorage

Humary использует обязательные cookie для безопасной авторизации и сохранения сессии. Cookie авторизации имеет защитные атрибуты HttpOnly, Secure в production-среде и SameSite=Lax.

В localStorage браузера могут сохраняться язык интерфейса, состояние сайдбара, выбор cookie, сведения для отображения профиля и временные черновики текста или результата. Пользователь может удалить эти данные через настройки браузера.

Подробная информация доступна на странице Cookie.

6. Сторонние сервисы

  • GigaChat — получает текст, необходимый для обработки или стилистического анализа;
  • Яндекс ID и VK ID — используются только при выборе соответствующего способа входа и могут передавать email, имя и ссылку на аватар;
  • Gravatar — может использоваться как резервный источник аватара; для запроса аватара передаётся необратимый хеш адреса электронной почты;
  • почтовый провайдер — используется для отправки кодов входа и иных сервисных сообщений.

Humary не продаёт персональные данные и не передаёт их третьим лицам для рекламы.

7. Защита данных

В production-среде соединение с сайтом защищается HTTPS. Пароли не используются для входа, а сессии авторизации защищены техническими ограничениями. Доступ к данным ограничивается техническими и организационными мерами, необходимыми для работы сервиса.

8. Права пользователя

Пользователь может запросить сведения об обработке своих данных, уточнить их, очистить историю или удалить аккаунт. По вопросам конфиденциальности и обработки данных обратитесь через страницу контактов.

9. Изменение политики

Новая редакция Политики публикуется на этой странице с указанием даты обновления. Продолжая использовать сервис после публикации новой редакции, пользователь знакомится с её актуальным содержанием.
