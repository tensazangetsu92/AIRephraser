# Поисковые запросы Humary

Это предварительная карта тем и подходящих страниц, а не список запросов с подтверждённым спросом. Владелец сайта уточнил, что показы на предоставленном скриншоте Google Search Console связаны с его собственными проверками. Поэтому эти показы и клики не используем для оценки органического интереса или выбора приоритетных страниц. Вордстат и актуальный экспорт Search Console пока недоступны; частотность запросов и текущие позиции здесь не указаны.

Следующий шаг — получить независимую оценку спроса по запросам и проверить индексацию соответствующих URL. Затем в Search Console открыть «Эффективность», выбрать страницу и сравнить запросы, показы, клики и среднюю позицию за сопоставимые периоды, исключив собственные проверки владельца по датам, насколько это возможно. В Яндекс Вебмастере проверить те же запросы, когда сервис снова станет доступен. При появлении данных пересмотреть приоритеты страниц. Отсутствие строки в отчёте не доказывает нулевой спрос: часть запросов может не отображаться в таблице.
